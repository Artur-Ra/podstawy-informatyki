# HTTP: 1XX:
- statusy informacyje, informują o stanie zapytania
# HTTP: 2XX:
- statusy powodzenia, informują o poprawnym przetworzeniu zapytania
# HTTP: 3XX:
- statusy przekierowania, informują o przekierowaniu żądania w inne miejsce
# HTTP: 4XX:
- statusy błędu, informują o błędzie aplikacji klienta
# HTTP: 5XX:
- statusy błędu, informują o błędzie aplikacji serwera
